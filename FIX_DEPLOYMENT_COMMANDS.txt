================================================================================
WHAT WAS CHANGED
================================================================================

Before (causing 404 errors):
- Assets were being requested from: https://username.github.io/assets/...
- But they were actually at: https://username.github.io/repo-name/assets/...

After (fixed):
- The build process now sets: VITE_BASE_PATH=/repo-name/
- Assets will be requested from: https://username.github.io/repo-name/assets/
- This matches where GitHub Pages actually serves them

The workflow file now contains:
```yaml
- name: Build
  run: npm run build
  env:
    VITE_BASE_PATH: /${{ github.event.repository.name }}/
```

This automatically uses your repository name, so it works for any repo!
